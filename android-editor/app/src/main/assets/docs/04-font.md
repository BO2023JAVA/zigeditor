# 字体与资源

## 换字体

界面字体就是项目里的 `core/font.ttf`，直接替换这个文件即可：

- 文件名保持 `font.ttf` 不变
- 字体在编译期内嵌进 `.so`，换完必须重新编译并安装，运行中的 APK 不会变
- 字体越大，产物越大、编译略慢
- 删除该文件会导致编译失败

## 中文显示

- ASCII 字符走内置点阵图集，速度快
- 中文等字符由 SDL_ttf 从内嵌字体动态栅格化，按屏幕密度放大，高密度屏不糊
- 默认字号是 18dp，可以在 `applyTheme` 里调整
- 字体缺字时对应字符画不出来，建议用覆盖常用汉字的字体

## 其他资源

目前项目只会打包字体；图片、音效等资源还没有统一的加载约定，需要自己在 `app.zig` 里处理或改渲染后端。
